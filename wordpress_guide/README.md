# Enterprise WordPress Engineering Guide

## Overview
This repository contains a comprehensive curriculum for Senior WordPress Engineers. It moves beyond basic theme development into high-scale architecture, headless implementations, and DevOps practices.

## Curriculum Structure

### Core Modules
1.  **Modern Setup (Bedrock)**: Composer-managed WordPress, environment variables, and folder structure.
2.  **Templating (Timber & Twig)**: MVC pattern in WordPress, separating logic from views.
3.  **Advanced Gutenberg**: Building custom blocks with React and ACF.
4.  **DB & Performance**: PostgreSQL integration, Redis object caching, and query optimization.
5.  **AWS Fargate & CI/CD**: Containerizing WordPress and deploying to serverless infrastructure.
6.  **Headless WordPress**: Using WPGraphQL and Next.js as a frontend.
7.  **Security Hardening**: Securing the admin, headers, and file permissions.
8.  **Plugin Development**: Object-Oriented Programming (OOP) for plugins.
9.  **WooCommerce Customization**: Advanced hooks and template overrides.
10. **Legacy Migration**: Strategies for refactoring old codebases.

### Interview Preparation
A set of 10 interview guides covering everything from Core APIs to System Design.

### Real-World Use Cases
Practical "Jira Ticket" scenarios to test your skills in a simulated work environment.
