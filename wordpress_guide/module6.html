Module 6: Headless WordPress

Decoupling the Frontend.

WPGraphQL & Next.js

Use WordPress as a CMS only, and build the frontend with modern JS frameworks.

Key Concepts

  • WPGraphQL: Exposing data via a typed schema.
  • Next.js: Static Site Generation (SSG) from WP data.
  • Revalidation: Updating static pages when content changes.
