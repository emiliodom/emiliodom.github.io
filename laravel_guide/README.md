# Laravel 12 + TALL Stack: Senior Developer Path

A professional curriculum for PHP developers aiming for **Senior Laravel** roles, focusing on the TALL stack (Tailwind, Alpine, Laravel, Livewire) and Filament.

## 📚 Curriculum Modules

| Module | Topic | Description |
| :--- | :--- | :--- |
| **[Module 1](module1.html)** | **Modern PHP & Setup** | PHP 8.2+ features, Docker (Sail), and strict typing. |
| **[Module 2](module2.html)** | **Laravel 12 Core** | Service Container, Facades, and Request Lifecycle. |
| **[Module 3](module3.html)** | **Database & Eloquent** | Advanced relationships, scopes, and performance (N+1). |
| **[Module 4](module4.html)** | **Livewire 3** | Building dynamic SPAs with PHP. |
| **[Module 5](module5.html)** | **Alpine & Tailwind** | Frontend interactivity and utility-first styling. |
| **[Module 6](module6.html)** | **Filament Admin** | Rapidly building admin panels and dashboards. |
| **[Module 7](module7.html)** | **Queues & Redis** | Background jobs, caching, and event-driven architecture. |
| **[Module 8](module8.html)** | **Testing & CI/CD** | TDD with Pest PHP and deployment pipelines. |
