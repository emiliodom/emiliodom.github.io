# Next.js 14+ App Router: Zero to Production

A comprehensive curriculum designed to take you from React developer to **Senior Next.js Engineer**.

This guide focuses on the **App Router** paradigm, Server Components (RSC), Server Actions, and the modern "full-stack frontend" architecture.

## 📚 Curriculum Modules

| Module | Topic | Description |
| :--- | :--- | :--- |
| **[Module 1](module1.html)** | **App Router & RSC** | The mental model shift: Server vs. Client Components. |
| **[Module 2](module2.html)** | **Routing & Layouts** | File-system routing, nested layouts, and templates. |
| **[Module 3](module3.html)** | **Server Actions** | Mutations, form handling, and revalidation without API routes. |
| **[Module 4](module4.html)** | **Client Interactivity** | `use client`, hooks, and managing state in a server-first world. |
| **[Module 5](module5.html)** | **Styling** | Tailwind CSS, CSS Modules, and font optimization. |
| **[Module 6](module6.html)** | **Database** | Connecting to a DB with Prisma/Drizzle in a serverless environment. |
| **[Module 7](module7.html)** | **Auth** | Authentication with NextAuth.js (Auth.js) v5. |
| **[Module 8](module8.html)** | **Deployment** | Vercel, Edge Runtime, and production optimization. |
